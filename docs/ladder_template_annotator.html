Ladder Template Annotator

Manual-first annotation tool for local Hex templates. The JSON it exports is designed so an OpenCV prefill step can populate the same structure later.

Metadata

Image

Use the source image as a guide only. The exported JSON stores the image name and current alignment settings, but not the image bytes.

Grid

Keyboard shortcuts: 0 ignored, 1 empty, 2 red, 3 blue, 4 plus, 5 minus, 6 shaded. Arrow keys nudge the grid when focus is not in a text field. Right-click a cell to erase it.

Export / Import

Annotated cells

Overlay View

Click to paint the selected state. Click again with the same state selected to toggle back to ignored.
