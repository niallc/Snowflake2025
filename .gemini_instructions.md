# Project Instructions

## Environment Setup
- **Virtual Environment**: Always activate the virtual environment before running Python commands:
  ```bash
  source hex_ai_env/bin/activate
  ```
- **PYTHONPATH**: Ensure the project root is in the python path:
  ```bash
  export PYTHONPATH=.
  ```
- **Combined Command**:
  ```bash
  source hex_ai_env/bin/activate && export PYTHONPATH=. && python3 <script>
  ```

## Temporary Files
- Do not create temporary files in the project root.
- Use the `temp/` directory for any temporary scripts or debug files.
- Create subdirectories in `temp/` for specific features or tasks (e.g., `temp/feature_name/`).
